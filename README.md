## 🔐 Obtener Credenciales de Meta

### Paso 1: Crear Meta Business Account

1. Ir a https://business.facebook.com
2. Hacer clic en "Create Account"
3. Llenar datos básicos de tu empresa
4. Confirmar email

### Paso 2: Crear WhatsApp Business App

1. En Business Manager, ir a "Apps"
2. Click "Create App"
3. Seleccionar "Business" como app type
4. Rellenar:
   - App name: "Atlas Chatbot"
   - Contact email: tu email
   - Purpose: Customer Communications
5. Click "Create App"

### Paso 3: Configurar WhatsApp

1. En tu app, buscar "WhatsApp" product
2. Click "Set Up"
3. Seleccionar "Get Started"
4. Click "Create Test Number" (si no tienes business account verificado)
   - O conectar tu número de negocio existente

### Paso 4: Obtener Credenciales

En la sección "API Setup" encontrarás:

- **WHATSAPP_PHONE_NUMBER_ID**: En "Phone numbers" → Tu número → ID
- **WHATSAPP_ACCESS_TOKEN**: En "System User" → Generate token
  - Necesita permisos: `whatsapp_business_messaging`, `whatsapp_business_phone_number_management`
- **WHATSAPP_APP_SECRET**: En "Settings" → "Basic" → App Secret
- **WHATSAPP_VERIFY_TOKEN**: Cualquier valor único (ej: `atlas-verify-token-abc123`)

### Paso 5: Configurar Webhook en Meta

1. En "Webhooks" → "Edit subscription"
2. Agregar URL: `https://tu-backend-url.railway.app/api/webhooks/whatsapp`
3. Verify Token: el valor que pusiste en WHATSAPP_VERIFY_TOKEN
4. Suscribirse a eventos: `messages`, `message_template_status_update`

### Option 2: Heroku (Classic)

```bash
# 1. Install Heroku CLI
npm install -g heroku

# 2. Login
heroku login

# 3. Create app
heroku create atlas-whatsapp-bot

# 4. Add PostgreSQL addon
heroku addons:create heroku-postgresql:standard-0

# 5. Set environment variables
heroku config:set WHATSAPP_ACCESS_TOKEN="your_token"
# ... repeat for all variables

# 6. Deploy
git push heroku main

# 7. Run migrations
heroku run npm run prisma:migrate:deploy
```

### Option 3: Docker (Any Cloud)

```bash
# Build
docker build -t atlas-bot ./backend

# Run
docker-compose -f docker-compose.prod.yml up -d

# Migrations
docker-compose exec backend npm run prisma:migrate:deploy
docker-compose exec backend npm run init:prod
```

## 🔄 How It Works

```
Client sends WhatsApp message
         ↓
    Meta API → Webhook
         ↓
Backend receives POST /api/webhooks/whatsapp
         ↓
WhatsApp service parses message
         ↓
Messages service processes text
         ↓
AI service generates response (OpenAI or Mock)
         ↓
Backend sends response via Meta API
         ↓
   Client receives on WhatsApp ✅
```

## 📊 API Endpoints

### Public Endpoints (no auth required)

```
GET  /api/webhooks/whatsapp?hub.mode=subscribe&hub.verify_token=TOKEN&hub.challenge=CHALLENGE
POST /api/webhooks/whatsapp                    # Receive WhatsApp messages
GET  /api/products                             # List products
GET  /api/products/:id                         # Get product
GET  /api/categories                           # List categories
GET  /api/categories/:id                       # Get category
POST /api/messages/process                     # Process message
POST /api/auth/login                           # Admin login
```

### Protected Endpoints (JWT required)

```
POST   /api/products                           # Create product
PATCH  /api/products/:id                       # Update product
DELETE /api/products/:id                       # Delete product

POST   /api/categories                         # Create category
PATCH  /api/categories/:id                     # Update category
DELETE /api/categories/:id                     # Delete category

GET    /api/auth/me                            # Get current user
```

## 🐛 Troubleshooting

### Webhook not receiving messages
1. Check webhook URL is public HTTPS
2. Verify WHATSAPP_VERIFY_TOKEN in Meta matches code
3. Check API logs: `railway logs --follow`

### Database connection error
1. Check DATABASE_URL format
2. Verify PostgreSQL is running
3. Test connection: `npx prisma db push`

### Admin login fails
1. Verify admin user exists: `railway run npm run init:prod`
2. Check JWT_SECRET is set
3. Verify database is migrated: `railway run npm run prisma:migrate:deploy`

### OpenAI errors
1. OpenAI is optional - bot uses MockAI by default
2. To use OpenAI: set OPENAI_API_KEY and LOCAL_MODE=false
3. Test key: `curl https://api.openai.com/v1/models -H "Authorization: Bearer YOUR_KEY"`
